# Support

## If you need help with your own name or gender-marker change

**This project cannot help you personally, and nothing here is legal advice.**
It is a reference tool, and it is explicitly pre-launch: no record in its corpus has
yet been verified by a named human (see the launch-gate table in
[`README.md`](./README.md)).

For actual help with your situation, these are the kinds of organisations that do it:

- **Your state's legal-aid organisation** — many run free name-change clinics.
  The app lists per-jurisdiction referrals it has on file under each checklist.
- **[Advocates for Trans Equality (A4TE) — ID Documents Center](https://transequality.org/documents)** —
  human-curated, plain-language guides for every state. Each checklist here links the matching guide.
- **[Lambda Legal Help Desk](https://www.lambdalegal.org/help)**
- **[Transgender Law Center](https://transgenderlawcenter.org/help)**

If a court clerk, DMV, or vital-records office tells you something different from what
this project says, **believe them, not us** — and please
[tell us](https://github.com/ChelseaKR/trans-docs-navigator/issues/new?template=law-changed.md),
because it means a record here is wrong.

## If you found something wrong in the data

Open a [law-changed issue](https://github.com/ChelseaKR/trans-docs-navigator/issues/new?template=law-changed.md).
You do not need to know the fix — telling us the page changed is enough.

## If you hit an accessibility barrier

Open an [accessibility issue](https://github.com/ChelseaKR/trans-docs-navigator/issues/new?template=accessibility-barrier.md).
These are treated as bugs, not enhancements.

## If you want to contribute

Read [`CONTRIBUTING.md`](./CONTRIBUTING.md) first — the verification bar is the whole
point of the project, and it is stricter than most repos.

The most valuable contribution is
[verifying a record](https://github.com/ChelseaKR/trans-docs-navigator/issues/new?template=verify-a-record.md).
You do not need to be a lawyer to do it.

## If you found a security or privacy problem

Please **do not** open a public issue. Use
[private vulnerability reporting](https://github.com/ChelseaKR/trans-docs-navigator/security/advisories/new);
see [`SECURITY.md`](./SECURITY.md). Users of this project may be in hostile
jurisdictions, so a privacy bug is a safety bug.
