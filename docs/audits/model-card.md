# Model Card — Trans Docs Navigator guidance

> Last verified: 2026-05-31 · Recheck cadence: per generator/model change.

## Intended use
Produce **grounded, cited, plain-language** guidance and ordered checklists for legal
name and gender-marker changes in supported US jurisdictions. **Information, not legal
advice.** Not a filing service; makes no representations about individual legal outcomes.

## System design (how it speaks)
Generation is **retrieval-mandatory** (ROADMAP §6, ADR-1): the generator only ever
sees records returned by retrieval, and every substantive sentence carries a citation
to a corpus record. Output passes through `citation.enforce()` before it can render;
any uncited or unsupported claim is **rejected, not shown** (guardrail #1).

### Generator
- **Default (this build): `GroundedComposer`** — a deterministic extractive composer.
  It is faithful by construction (a claim's text derives from its cited record) and
  makes the eval reproducible. This is why groundedness measures 100%.
- **Production seam: `BedrockGenerator`** — Claude on AWS Bedrock (Haiku-first, Sonnet
  for harder synthesis) with a retrieval-grounded, citation-required prompt. Its output
  is subject to the *identical* post-generation enforcement, so an ungrounded sentence
  from the model is rejected rather than rendered. Unconfigured in this environment
  (no AWS credentials).

## Behaviours
- **Refusal:** when no current record backs a request, the system says it does not have
  verified information and points to the official source — it never fabricates.
- **Freshness degradation:** stale/volatile records are surfaced as "needs
  reverification" and never served as current fact.
- **Uncertainty:** discretionary (court/clerk-dependent) steps are explicitly framed as
  varying, not guaranteed.

## Evaluation
See `eval-report.md` (regenerated by `make eval`). Metrics: groundedness ≥ 0.95,
factual accuracy ≥ 0.98, refusal safety = 1.0, citation coverage = 1.0, plus
disaggregated accuracy by jurisdiction and language.

## Limitations & honest scope
- Accuracy is measured against a gold set co-authored with the seed corpus; not an
  independent accuracy claim (see `data-card.md`).
- The deterministic composer is intentionally conservative/templated; it does not
  paraphrase or synthesize across records the way a Bedrock-backed generator would.
- No real Bedrock evaluation has run in this environment.
